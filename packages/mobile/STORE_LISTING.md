## Descrição completa (máx. 4000 caracteres)

```
Aprender inglês "de curso" não prepara você para o inglês que se fala de verdade no trabalho: em uma daily standup, revisando um pull request, respondendo um incidente em produção, ou negociando uma proposta de emprego.

O TECHSPEAKING é uma coleção de audiobooks curtos, com cenas reais do dia a dia de quem trabalha com tecnologia — não diálogos genéricos de curso de idiomas.

O QUE VOCÊ ENCONTRA
- 25 audiobooks reais, cerca de 7 horas de conteúdo, dos níveis iniciante ao avançado
- Temas técnicos: daily standup, code review, arquitetura, debugging em produção, testes, segurança, CI/CD
- Temas de carreira: entrevista de emprego, negociação salarial, apresentação para stakeholders, 1:1 com o gestor, trabalho remoto

COMO FUNCIONA
- Ouça o áudio narrado enquanto acompanha a transcrição completa na tela
- Toque em qualquer palavra do texto para ver tradução, pronúncia e um exemplo de uso — não só as palavras já marcadas
- Pratique com flashcards de repetição espaçada, criados automaticamente a partir das palavras que você clicou
- Acompanhe sua sequência de estudo e seu progresso no painel

Comece gratuitamente com 2 audiobooks completos. O acesso a todo o catálogo é um pagamento único — sem mensalidade.
```
